# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue, pull request, or
community chat.

Use GitHub's [private vulnerability reporting form](https://github.com/nomyr-security/nomyr/security/advisories/new)
or email [oss@nomyr.io](mailto:oss@nomyr.io). Private vulnerability reporting
is enabled for this repository. Include:

- a concise description and potential impact;
- the affected version, commit, component, or contract;
- safe reproduction steps or a proof of concept;
- a secure way to contact you.

Do not include live credentials, personal data, customer data, or private
infrastructure details. The project will coordinate validation and disclosure
timing with the reporter. No fixed response or disclosure deadline is
currently published.

The local demo is synthetic and loopback-only. Do not expose it publicly or
connect it to production credentials while reporting an issue.
