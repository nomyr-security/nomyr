These local-output errors are separate from public registry scan evidence.

The same run scanned the exact pinned PostgreSQL, ClickHouse, and NATS registry digests in the table above. The PR branch now builds services sequentially and checks `docker image inspect` before scanning local tags, so a failed build is reported explicitly while remaining service builds and public-registry scans continue.
