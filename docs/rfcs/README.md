# Request for Comments

Use an RFC for a proposal that affects multiple components, public contracts,
security boundaries, licensing, or contributor-facing governance. A focused
implementation detail may use an issue and ADR instead.

## Process

1. Open a GitHub issue to establish scope and link any blocking decisions.
2. Propose `NNNN-short-title.md` in this directory. Include status, authors,
  context, goals and non-goals, options, security and privacy analysis,
  compatibility and licensing effects, rollout, validation, and open questions.
3. Keep the RFC proposed while discussion is active. Record unresolved concerns
  and requested evidence; do not describe proposals as implemented behavior.
4. When the authorized decision-makers accept, link the resulting ADR or issue
  and update this RFC's status. A rejected or withdrawn proposal should also
  preserve its rationale.

Named human decision owners and the ratification threshold are not yet
published. An RFC or merge alone does not establish approval. See
[`../adr/README.md`](../adr/README.md) for durable decisions.
