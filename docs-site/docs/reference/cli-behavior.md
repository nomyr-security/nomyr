---
title: CLI behavior
---

The CLI is a Phase 0 local scaffold. Structured command failures include a stable error code, explanation, cause, fix, and documentation link. Connector and rule scaffolds produce starter files; they do not implement providers or rule execution.

Usage metrics are anonymous CLI operational analytics, enabled by default with an immediate opt-out. Set `NOMYR_CONFIG_HOME` to an isolated directory for local tests. See the repository's public `TELEMETRY.md` for the client-side behavior and privacy limits.
