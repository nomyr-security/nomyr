# Nomyr

Nomyr is an early-stage, specification-first project building toward an open-source platform for non-human identity security. Its scope includes service accounts, workload identities, credentials, and AI agents.

## Project status

This public repository is an initial project introduction. It does not yet contain an implementation or a production-ready release. Planned capabilities should not be treated as available security controls.
