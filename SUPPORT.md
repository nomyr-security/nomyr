# Support

Nomyr is pre-release Phase 0 software. Product services and production support
are not established; the checked-in demo is synthetic and intended for local,
loopback-only use.

- For reproducible bugs and feature requests, use the repository's GitHub issue
  forms: https://github.com/nomyr-security/nomyr/issues/new/choose
- For security vulnerabilities, follow [SECURITY.md](SECURITY.md) and report
  privately. Do not post exploit details in issues or discussions.
- For contribution process questions, see [CONTRIBUTING.md](CONTRIBUTING.md).

No response-time, service-level, or staffed support commitment is currently
published. Do not include credentials, personal or customer data, or private
infrastructure details in public reports.
